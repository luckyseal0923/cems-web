團隊模擬訓練課程
授課講師 各學系老師
報名截止日

    在專業領域實習生涯裡，許多繁瑣的臨床工作，卻不見得有人教過，本課程藉由模擬日常職場方式，學習如何與醫療團隊的合作，以順利完成每個任務，讓學生學會領導一個團隊須具備的溝通技巧以及醫學倫理與法律相關思維，訓練學生於跨領域團隊合作之情境中學習醫學倫理、溝通能力及團隊資源管理等知識、技能和態度。

     

課程介紹

團隊模擬訓練課程　( Team Resource Management, TRM )
(一)目的：訓練醫學系學生在跨領域團隊合作的情境中學習醫學倫理、溝通能力、團隊資源管理等領域的知識、技能和態度
(二)學習目標：
在採用以任務導向的情境經由討論及演練後能做到下列各項：
1.運用倫理原則分析倫理難題並作出倫理抉擇
2.對醫病互動的情境提出溝通策略及選擇適切的溝通內容及程序
3.體驗團隊資源管理案件並選擇適切的TRM工具

實習醫學生在醫院藉由實習領受醫療工作的點點滴滴，在他們的實習生涯裡，有許多繁瑣的的臨床工作，在我們過去實習的生活中，天天做的事，卻不見得有人教過。

希望讓實習醫學生實習的過程中，能藉由模擬的方式，來教授他們在日常工作中，該如何與醫療團隊的合作，順利完成每個任務，讓學生免於恐懼的冒險去執行任務。

藉由這樣的課程，學會領導一個團隊時，須具備的溝通技巧以及醫學倫理與法律的相關思維，我們訓練讓醫學系學生在跨領域團隊合作的情境中學習醫學倫理、溝通能力、團隊資源管理（team resource management，以下簡稱TRM）等領域的知識、技能和態度。
